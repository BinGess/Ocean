# MindFlow 项目功能与亮点介绍

## 项目定位

MindFlow 是一款围绕「情绪觉察」与「自我理解」构建的移动应用。它以非暴力沟通（NVC）框架为核心，把用户日常的碎片想法、情绪波动、关系事件和身体感受沉淀为可回顾、可分析、可行动的个人记录。

项目当前以 Flutter 构建 iOS / Android 双端体验，结合本地存储、AI 语音识别、NVC 情绪分析、周维度洞察、Sarah 来信、账号同步与隐私保护能力，形成了一套从「记录」到「理解」再到「持续陪伴」的产品闭环。

## 核心功能

### 1. 瞬记：低负担记录当下

瞬记是应用的主入口，面向用户在日常生活中快速捕捉情绪和想法的场景。

- 支持语音录制与文字记录，降低记录门槛。
- 录音完成后可通过豆包 ASR 转写为文本。
- 支持记录时间选择，方便补记过去发生的事件。
- 首页通过柔和动效、引用文案和沉浸式录音交互，营造安静、专注的记录氛围。

### 2. 多种处理模式：从保存到洞察逐级深入

用户完成一次记录后，可以按需要选择不同处理深度。

- 仅记录：保留原始文本，适合快速保存想法。
- 添加情绪：为记录补充情绪标签和需要标签。
- NVC 分析：基于「观察、感受、需要、请求」结构生成完整分析。

这种分层设计让用户既可以轻量使用，也可以在需要时获得更深入的情绪理解。

### 3. NVC 情绪洞察

应用将非暴力沟通框架产品化，帮助用户把模糊的情绪表达拆解为更清晰的内在结构。

- 观察：提炼客观发生的事实，减少自我评判。
- 感受：识别真实情绪，而不只停留在事件描述。
- 需要：挖掘情绪背后未被满足的核心需要。
- 请求：生成更具体、可执行的下一步建议。
- 支持 Coze AI 智能体优先分析，并具备豆包 LLM 和默认结果的降级能力。

### 4. 每日记录与日总结

记录页按日期组织用户的所有碎片内容，让长期记录形成可浏览的时间线。

- 记录按天聚合展示，支持每日心情选择。
- 当某天记录达到一定数量后，可自动生成 AI 日总结。
- 日总结包含情绪关键词、一句话概括和 0-10 情绪分数。
- AI 推荐心情可被用户手动覆盖，保留用户对自身状态的最终判断权。

### 5. 本周概览与周洞察

应用支持将一周内的记录汇总为更高层次的情绪报告。

- 统计本周记录数量、活跃天数和高峰记录时段。
- 汇总高频情绪与高频需要，帮助用户发现重复模式。
- 生成情绪概览、高频情境、模式假设和行动建议。
- 支持历史洞察报告查看与分享。

周洞察把零散的日常记录转化为周期性反馈，帮助用户看见「我最近一直在经历什么」。

### 6. Sarah 来信：陪伴式周报体验

Sarah 是项目中更具情感化表达的一层能力。它不只是数据报告，而是以「来信」形式为用户总结一段时间内的状态。

- 支持欢迎信、周信和历史信件。
- 周信由服务端定时任务生成，客户端只负责拉取展示，避免重复触发。
- 信件支持已读状态、删除、归档和插画展示。
- 通过「From Sarah」的表达方式，把冷冰冰的分析转化为更温柔的陪伴体验。

### 7. 账号、同步与数据迁移

项目已经具备完整的账号与云端数据同步思路。

- 支持邮箱 / 手机验证码登录。
- 未登录时数据保存在本机。
- 登录后可将本地记录、每日心情、日总结、洞察报告、个人资料等迁移并同步到服务端。
- 通过数据归属标记区分本地数据与账号数据，降低登录、登出、切换账号时的数据混淆风险。
- 支持服务端快照恢复，提升多设备与重装后的数据连续性。

### 8. 隐私与安全保护

情绪记录具有很强的私人属性，因此项目在隐私保护上有专门设计。

- 支持应用锁，可使用密码或系统生物识别解锁。
- App 进入后台时显示隐私遮罩，降低切屏泄露风险。
- AI 服务授权可由用户主动开启或关闭。
- 支持账号删除、本地数据清理等数据管理能力。

### 9. 数据导出与分享

项目支持把长期积累的记录转化为可带走、可分享的内容。

- 支持导出记录和洞察信息。
- 支持按时间范围筛选导出内容。
- 支持 Markdown 等结构化格式。
- 支持洞察海报和分享页面，便于将特定报告以更美观的形式保存或分享。

### 10. Pro 与订阅能力

项目已接入应用内购买能力，为后续商业化提供基础。

- 使用 `in_app_purchase` 接入 App Store 订阅。
- 当前配置包含月度订阅商品。
- 导出等高级功能可通过 Pro 权限控制。
- 内部调试模式与真实订阅逻辑分离，便于开发测试。

## 产品亮点

### 1. 不是普通日记，而是「情绪理解工具」

MindFlow 的核心不是单纯保存文本，而是围绕 NVC 框架将记录转化为自我理解：

- 从事件到感受。
- 从感受到需要。
- 从需要到行动请求。
- 从单条记录到长期模式。

这让产品更接近情绪教练和自我观察系统，而不是传统备忘录。

### 2. 记录成本低，分析深度可选

用户可以只用几秒钟完成一次语音瞬记，也可以在重要事件后选择完整 NVC 洞察。轻量记录和深度分析并存，避免用户一开始就被复杂表单劝退。

### 3. AI 能力嵌入真实工作流

项目中的 AI 并不是孤立聊天入口，而是嵌入到具体任务中：

- 录音后自动转写。
- 记录后生成 NVC 分析。
- 当日记录足够时生成日总结。
- 一周后生成周洞察和 Sarah 来信。

这种设计让 AI 更像后台能力，服务于用户的反思节奏，而不是打断用户。

### 4. 兼顾理性分析与情感陪伴

项目同时拥有两种表达层：

- 本周概览、趋势、标签、分数，适合理性回顾。
- Sarah 来信、插画、柔和文案，适合情感陪伴。

这使产品既能提供清晰反馈，也能保留温度。

### 5. 面向长期使用的数据体系

项目不仅实现了单机记录，还开始建设账号、同步、数据归属、快照恢复、导出等长期使用所需的能力。这意味着用户的情绪数据可以随着时间累积，而不是停留在一次性体验。

### 6. 隐私意识强，适合敏感内容场景

从应用锁、后台遮罩、AI 授权开关，到本地数据和账号数据的隔离，项目对情绪类应用的隐私风险有明确处理。这是情绪记录产品能否被长期信任的重要基础。

### 7. 技术架构清晰，便于持续扩展

项目采用 Clean Architecture + BLoC，核心结构清晰：

- `domain` 承载实体、仓储接口和用例。
- `data` 负责模型、本地 Hive 数据源、远程接口和仓储实现。
- `presentation` 负责页面、组件和 BLoC 状态管理。
- `core` 沉淀网络、主题、依赖注入、同步、隐私、安全等基础能力。

这种分层让录音、记录、AI 分析、洞察、Sarah、账号同步等模块可以相对独立演进。

### 8. 具备跨端产品化基础

Flutter 技术栈让项目天然具备 iOS / Android 双端复用能力；同时项目已经包含国际化、本地化文案、权限配置、App Store 订阅、隐私与导出等移动端产品化环节，具备继续打磨上线的基础。

## 典型用户流程

```text
打开应用
  ↓
完成新手引导 / 登录引导
  ↓
在「瞬记」页录音或输入文字
  ↓
选择仅记录、添加情绪或 NVC 分析
  ↓
记录进入「记录」时间线
  ↓
当天记录积累后生成日总结
  ↓
一周记录积累后生成周洞察
  ↓
Sarah 以信件形式回顾本周状态
  ↓
用户可导出、分享、同步或继续长期记录
```

## 技术亮点

- Flutter + Dart 跨平台实现，统一维护移动端体验。
- BLoC 事件驱动状态管理，录音、记录、洞察、Sarah、语言等模块状态清晰。
- Hive 本地存储，支持离线保存与快速读取。
- Dio + WebSocket 集成远程能力，包含豆包 ASR 二进制协议与 LLM / Coze SSE 调用。
- GetIt 依赖注入，便于模块替换和测试。
- Freezed / JSON 序列化 / Hive Generator 减少样板代码。
- 完整的错误处理与降级策略，AI 失败时尽量不阻断核心记录流程。
- 单元测试覆盖 BLoC、数据源、仓储、用例与关键组件，为持续迭代提供保障。

## 可用于对外介绍的一句话

MindFlow 是一款基于 NVC 非暴力沟通框架的情绪觉察应用，帮助用户用语音或文字低成本记录日常感受，并通过 AI 分析、日总结、周洞察和 Sarah 来信，把零散情绪转化为可理解、可回顾、可行动的自我陪伴。
